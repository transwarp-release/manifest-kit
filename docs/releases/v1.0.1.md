# Manifest Kit v1.0.1

这是一个保持现有命令和文件格式兼容的小幅修订版本。

## 变更

- CLI 顶层帮助增加清单生成、目录校验和清单比对示例。
- 明确退出码、报告存放位置、glob 大小写及基线排除规则的使用方式。
- 新增持续保留历史条目的 `CHANGELOG.md` 和版本更新验收说明。

## 验证

```text
python -B -m manifestkit --version
python -B -m unittest discover -s tests -v
python -B scripts/run_demo.py
```

程序版本应为 `manifest-kit 1.0.1`，普通示例完成后返回 0。某些 Windows 环境无法创建符号链接时，对应测试会明确标记为跳过。

本版本只使用 Python 3.11+ 标准库，继续采用 MIT License，保留两个 AI skill 和原始示例数据。

该版本以独立提交及附注标签 `v1.0.1` 留存。本文件也是对应 GitLab Release 的发布说明来源，便于比较跨平台同步后的公告内容。
