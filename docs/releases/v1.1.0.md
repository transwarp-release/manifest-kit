# Manifest Kit v1.1.0

本版本新增文件扩展名统计，同时保留 v1.0.1 的命令帮助改进和全部历史变更说明。

## 新增功能

- `summary` 直接从已有 SHA-256 清单统计文件数量和总字节数，无需重新访问原始目录。
- 扩展名分类忽略大小写，复合文件名按最后一个后缀分类；无扩展名文件单独归类。
- 统计支持 UTF-8 JSON、Markdown 和可重复的排序输出。
- 完整示例和清单生成 skill 增加统计用法。

## 使用与验证

```text
python -B -m manifestkit --version
python -B -m unittest discover -s tests -v
python -B scripts/run_demo.py
python -B -m manifestkit summary .local/demo/manifest.json
```

程序版本应为 `manifest-kit 1.1.0`。示例统计为 4 个文件、643 字节，分别为 `.json` 1 个、`.md` 1 个、`.txt` 2 个。某些 Windows 环境无法创建符号链接时，对应测试会明确标记为跳过。

## 兼容性与历史

- 继续使用 Python 3.11+ 标准库和 MIT License，没有新增第三方依赖。
- `scan`、`verify`、`diff`、原清单格式及两个 skill 的原有用法保持兼容。
- `v1.0.1` 保留独立提交、附注标签和发布公告；本版本基于该版本继续开发，不替换旧版本记录。
- 仅将本版本交给自动化平台后，可按 `docs/version-update-test.md` 检查 GitHub 中的旧记录保留、标签导入和公告同步情况。
