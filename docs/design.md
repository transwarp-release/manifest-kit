# 设计与维护说明

## 模块

| 路径 | 责任 |
| --- | --- |
| `manifestkit/core.py` | 目录遍历、SHA-256、清单读取、差异计算 |
| `manifestkit/config.py` | 读取数据形式的 TOML 排除规则 |
| `manifestkit/reports.py` | 生成 Markdown 表格，对文件名转义 |
| `manifestkit/summary.py` | 从已有清单按扩展名统计文件数和总字节数 |
| `manifestkit/cli.py` | 参数、输出位置检查、退出码及报告写入 |
| `skills/` | 两套 AI 使用说明、参考文档及薄封装脚本 |
| `scripts/run_demo.py` | 可重复运行的完整正常示例 |
| `tests/` | Python 标准库单元测试及进程级 CLI/skill 验证 |

应用以 `python -m manifestkit` 运行，不需要构建或安装。此例交付的是源码仓库；后续发布 Python 软件包时可以再增加打包配置。

## 数据流

```text
指定目录 + 可选 TOML / glob
            |
            v
只读遍历普通文件 -> 分块 SHA-256 -> 排序的 Manifest
                                       |
                              UTF-8 JSON / Markdown
                                       |
                  已有 Manifest + 当前目录 / 另一份 Manifest
                                       |
                              文件差异与统计报告
```

校验时直接比较已扫描出来的相对路径映射，不按清单路径逐个打开文件。清单中的路径不得包含绝对路径、上级跳转或反斜杠；重复路径、无效摘要和负数大小会被拒绝。

## 行为约定

- 源目录只读；生成的报告应放在该目录之外，防止报告自身进入后续扫描。
- 扫描以 1 MiB 为块读取文件；检测到同一个已打开文件在读取前后发生大小或时间变化时，要求重试。
- 输入目录应在扫描期间保持稳定。本工具不提供文件系统快照或对并发目录替换的隔离。
- 扫描根目录必须是实际目录。遍历时跳过符号链接和 Windows reparse point，不展开链接目标。
- CLI 默认不覆盖报告；`--force` 使用输出目录内的临时文件和原子替换，针对单个文件写入。多个报告不是一个事务。
- Markdown 对文件名中的表格分隔符、链接标记和 HTML 字符做转义。
- 文件内容和清单数据不会作为命令或代码运行。应用与 skill 脚本没有网络调用、账号读取或平台发布逻辑。

## 维护边界

Python 解释器由运行环境提供，未包含在仓库中。仓库没有第三方运行或测试依赖，也没有需要取回的外部资源。其扫描结果仍需由实际工具针对实际提交确认。

清单并未签名。校验方应自行选择可信基线；`match` 只表示按该基线规则得到的文件字节一致。

## v1.1.0 扩展名统计

`summary` 接受原格式的 JSON 清单，经过相同的格式校验后按最后一个扩展名分组。分类忽略大小写，并使用 `(no extension)` 表示无扩展名文件。输出包含 `report_type`、`file_count`、`total_bytes` 和排序后的 `extensions` 数组；数组中的每组包含 `extension`、`file_count`、`total_bytes`。

该命令不重新读取源目录，不改变清单和应用默认排除规则，因此也能处理 v1.0.1 或原始 0.1.0 生成的清单。
