# 校验结果

| 退出码 | 含义 | 处理方式 |
| --- | --- | --- |
| `0` | 检查完成，`status` 为 `match` | 报告一致及统计 |
| `1` | 检查完成，`status` 为 `different` | 报告文件差异或排除策略变化 |
| `2` | 参数、输入格式、读取或写入错误 | 报告标准错误内容，不能宣称一致 |

`added` 表示当前存在但基线没有的文件，`removed` 表示基线存在而当前没有的文件。`changed` 按路径记录变化前后的字节数和 SHA-256；`unchanged_count` 统计一致文件。

对两份清单执行 `diff` 时，排除规则不同也视为差异，记录在 `exclusions_changed`、`baseline_exclude` 和 `current_exclude` 中。

`verify` 使用基线排除规则扫描当前目录，跳过符号链接和 Windows reparse point。工具不执行清单中的路径或任何文件内容。

报告只代表当前字节与基线是否一致。基线应来自调用方认可的来源；哈希本身不能确认作者身份，也不等同于病毒、漏洞或敏感信息扫描。
