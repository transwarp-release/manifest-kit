# 清单格式与排除规则

JSON 使用 UTF-8 编码，固定采用 `format_version: 1` 和 `hash_algorithm: "sha256"`。

| 字段 | 含义 |
| --- | --- |
| `exclude` | 本次扫描实际使用的排除规则，包含工具默认规则 |
| `files[].path` | 以 `/` 分隔的相对文件路径 |
| `files[].size` | 文件字节数 |
| `files[].sha256` | 64 个小写十六进制字符组成的 SHA-256 |

文件按相对路径排序，规则去重后排序。报告不记录扫描时间、用户名、主机名或绝对路径；输入字节和排除规则相同时，JSON 内容相同。

排除规则使用区分大小写的 glob。含 `/` 的规则匹配整个相对路径；不含 `/` 的规则也会匹配任一目录或文件名组件。因此 `*.tmp` 排除任意层级的临时文件，`cache` 排除任意层级名为 `cache` 的文件或目录。扫描遇到已排除的目录时不进入该目录。目录规则写成 `cache`，无需添加结尾的 `/`。

配置示例：

```toml
[scan]
exclude = ["*.tmp", "cache"]
```

`--exclude` 可以重复使用，并与 TOML 和默认规则合并。默认规则不能通过配置删除。空目录不产生文件条目；不读取符号链接、junction 或其他 Windows reparse point。

清单用于记录文件完整性，不是签名，也不是恶意软件检测报告。扫描过程中应保持源目录稳定。

## 按扩展名统计（v1.1.0）

`python -B -m manifestkit summary .local/manifest.json` 从现有清单输出统计，不需要访问原始目录。支持通用的 `--output`、`--markdown` 和 `--force` 报告参数。

统计按最后一个后缀归类并忽略大小写，`.TXT` 与 `.txt` 会合并，`archive.tar.gz` 计入 `.gz`。无扩展名文件使用 `(no extension)`。结果含总文件数、总字节数及每个分类对应的文件数与字节数；内容按扩展名排序。
